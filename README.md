# UtilOps GMP – app cài đặt

Lối vào cài đặt (PWA) cho phần mềm UtilOps GMP của Tổ Hệ thống Phụ trợ 2.
Repo này chỉ chứa vỏ app (trang khởi động, biểu tượng, manifest). Dữ liệu và tài khoản nằm trên máy chủ Google Apps Script / Google Drive của chủ sở hữu, không nằm ở đây.

- Mở: https://taichu97.github.io/utilops-app/
- Android / máy tính (Chrome, Edge): bấm "Cài đặt app".
- iPhone / iPad (Safari): Chia sẻ → Thêm vào MH chính.
